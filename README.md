# VOID PULSE

A mobile-friendly cosmic survival game.

## Play
Open `index.html` in any browser.

## Controls
- **Mobile:** Tap & hold to move, double-tap for sonar pulse
- **Desktop:** WASD to move, Space for pulse, mouse click to move

## Features
- Fog of war darkness system
- Sonar pulse mechanic
- Procedural audio (no files needed)
- Touch + keyboard support
- Progressive difficulty
